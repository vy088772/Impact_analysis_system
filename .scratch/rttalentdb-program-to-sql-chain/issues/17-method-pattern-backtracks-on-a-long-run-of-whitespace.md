## Agent Brief

**Category:** bug
**Summary:** `CSharpParser.METHOD_PATTERN` must run in linear time on a
long run of whitespace.

**Current behavior:**
`METHOD_PATTERN` starts with `^[ \t]*(?P<access>...)?\s*`. When the
`access` group is absent, `[ \t]*` and `\s*` can split one run of
whitespace in O(n²) ways. `strip_csharp_comments` changes each comment to
spaces, so a large block of commented code becomes one long run.
`TOPCSCY/TOPCSCY/Services/DSM/ToolExcelCreateService.cs` takes about 16 s
in `_extract_methods`. Two callers use the pattern: `_extract_methods`
and the method lookup after an HTTP attribute (the `re.search` on the 500
characters after the attribute).

**Desired behavior:**
Each match of `METHOD_PATTERN` starts on the line of the declaration. One
place in the pattern takes the whitespace after the access modifier. A
possible form: `^[ \t]*(?:(?P<access>public|private|protected|internal)\s+)?`,
then the rest of the pattern without change. The named groups (`access`,
`static`, `virtual`, `override`, `abstract`, `async`, `ret`, `name`) keep
their meaning. Both callers get the fix, because they use the same
constant.

**Key interfaces:**
- `CSharpParser.METHOD_PATTERN` — the regex to change. Update its comment
  with the reason, as the `CLASS_PATTERN` comment does.
- `MethodInfo.location` line number — changes only for a method with no
  access modifier after one or more blank lines. It moves to the line of
  the declaration.
- `match.start()` in `_extract_methods` also feeds `_extract_method_body`
  and `_routed_action_name`. Check that the method body and the action
  name do not change.
- `_CACHE_VERSION` in `service/scan_store.py` — rises by one, with a v51
  comment. Merge the main line version number first, because parallel
  tickets can take the same number.

**Acceptance criteria:**
- [ ] A test runs `METHOD_PATTERN` (with `re.MULTILINE`) on 20,000 spaces
  and finishes in less than one second.
- [ ] A test shows that `void Foo()` and `static int Bar()` after blank
  lines get the line number of the declaration.
- [ ] A test shows that declarations with an access modifier, modifiers,
  a generic return type, a tuple return type and a generic method name give
  the same groups as before.
- [ ] `ToolExcelCreateService.cs` in TOPCSCY parses in less than one
  second (`parse_file`, idle machine).
- [ ] With the old-to-new comparison script of ticket 16, the full
  `parse_file` result on each `.cs` file of the 16 scan roots is the same,
  except for `analysis_time` and the method line number above. Report each
  other difference. Do not accept it without a report.
- [ ] The scan cache version rises by one.
- [ ] The full test suite has no new failures. (Known failures on HEAD:
  `test_program_refresh`, `test_wrapper_decompilation`, and the collection
  errors of `test_search_roles.py` and `test_sp_tables.py`.)

**Out of scope:**
